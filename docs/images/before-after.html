Which local store should the sync layer use?

1. Hive - pure-Dart key-value store. Pros: no native
   dependencies, works on web today. Cons: no relational
   queries. Effort low, complexity low, value high.
   About 3 files, $0/mo.
2. SQLite (drift) - relational, fully queryable. Pros:
   real SQL and joins, typed queries. Cons: native deps
   on mobile, web needs a WASM build. Effort med,
   complexity med, value high. About 8 files, $0/mo.
3. Firestore offline cache - let the cloud SDK own
   persistence. Pros: sync for free. Cons: cloud sync
   stops being opt-in, cache size is capped. Effort low,
   complexity high, value low. Usage-billed.
